01

The Internet and the Web

What really happens when we open a website

What is the Internet?

A worldwide network of networks

Devices joined by cables, fibre, mobile towers and satellites
They follow common rules, called protocols
No single company or country owns it

Internet vs World Wide Web

Internet

The network itself.

Like the roads of a country.

World Wide Web

Web pages linked to each other, travelling over the Internet.

Like the buses running on those roads.

Email, WhatsApp and UPI also use the Internet, but they are not the Web

Where we use the Internet

Communication: email, WhatsApp, video calls
Money: UPI, net banking, bill payments
Government services: DigiLocker, UMANG, IRCTC
Learning: SWAYAM, NPTEL, YouTube
Shopping and entertainment: online shops, OTT, music

Website, web page, home page

Web page: one document that opens in the browser
Website: related web pages kept under one name
Home page: the first page of a website
Hyperlink: a click that takes us to another page

Website address: the URL

https://www.example.in/courses/web-design.html?batch=morning#fees
https://Protocol: how to talk to the server
www.example.inDomain name: which server
/courses/web-design.htmlPath: which page on that server
?batch=morningQuery: extra information for the page
#feesFragment: a place inside the page

IP address: the real address

Every device on the Internet has a number

IPv4: four numbers from 0 to 255, like 192.168.1.10
IPv6: longer, like 2001:db8::1
Names are for people, numbers are for machines

DNS: the phone book of the Internet

BrowserDNS serverIP addressWeb server
$ nslookup google.com

Try this in the Command Prompt to see the IP address behind a name

The browser

The software that fetches a page and draws it on the screen

Chrome, Edge, Firefox, Safari
It reads HTML, CSS and JavaScript, then shows the page
Press F12 for the developer tools

How a website works

1. Type the URL2. DNS gives the IP3. Request sent
4. Server finds the page5. Response returns6. Browser shows it

Request and response: this cycle repeats for every page, image and file

HTTP and HTTPS

HTTP: the rules for request and response on the web
HTTPS: the same, but encrypted and secure
200 OK, 404 Not Found, 500 Server Error

Front end and back end

Front end

What the user sees and touches.

Runs in the browser.

HTML, CSS, JavaScript

Back end

The logic and the data behind it.

Runs on the server.

PHP, Python, Java, Node.js, MySQL

The dining hall is the front end. The kitchen is the back end.

Client-side and server-side scripting

Client-side

The code runs in the user's browser.

Quick response, no waiting for the server.

JavaScript

Server-side

The code runs on the web server.

Can use the database. The user cannot see the code.

PHP, Python, Java, C#, Node.js

Static and dynamic websites

Static

Every visitor gets the same page.

Ready-made HTML files. Fast and cheap to host.

A school information site, a portfolio

Dynamic

The page is prepared for each request.

Content comes from a database.

IRCTC, net banking, online shopping

Responsive web design

One website that fits the mobile, the tablet and the desktop

Layouts that stretch and shrink
Images that resize with the screen
Media queries: different CSS for different widths

The three languages of the front end

HTML

Structure

The walls and rooms of a house

CSS

Presentation

The paint, tiles and furniture

JavaScript

Behaviour

The switches, fans and lift

Bootstrap is a ready-made collection of CSS and JavaScript

What converts a domain name into an IP address?

  1. HTTP
  2. The browser cache
  3. DNS
  4. HTML

DNS, the Domain Name System, is the phone book of the Internet.

Which language runs in the browser, on the client side?

  1. PHP
  2. JavaScript
  3. MySQL
  4. Python

JavaScript runs in the user's browser. PHP and Python run on the server.

A site that shows your own bookings after login is…

  1. A dynamic website

  4. A browser

Dynamic sites prepare the page for each user, using a database.

GET and POST

GET

The data is added to the URL and is visible.

Good for a search. The page can be bookmarked.

Not for passwords.

POST

The data goes inside the request, not in the URL.

Good for login, registration and file upload.

Can carry large data, even files.

CSS fundamentals

What is CSS?

Cascading Style Sheets

Controls colours, fonts, spacing and layout
Keeps the design separate from the content
One CSS file can style every page of a website

The syntax of a CSS rule

h1 {
  color: blue;
  font-size: 32px;
}
h1Selector: which elements to style
colorProperty: what to change
blueValue: what to change it to

Three types of CSS

Inline

Inside the tag, for one element

<p style="color:red">

Internal

In the head, for one page

<style>
  p { color: red; }
</style>

External

A separate file, for all pages

<link rel="stylesheet"
  href="style.css">

For a real website, always prefer an external style sheet

    msg.textContent = "Mobile must be 10 digits";
  } else {
    msg.textContent = "Registered. Thank you!";
  }
});

Local storage and session storage

localStorage

Stays even after the browser is closed.

Removed only by our code or by the user.

Theme choice, saved cart

sessionStorage

Stays only while the tab is open.

Cleared when the tab is closed.

A half-filled form, the current step

Both keep only text, on the user's computer. Never keep passwords in them.

const list = document.getElementById("list");

async function loadStudents() {
  try {
    const response = await fetch("students.json");
    const students = await response.json();

    for (const s of students) {
      const li = document.createElement("li");
      li.textContent = `${s.name}, ${s.city}`;
      list.append(li);
    }
  } catch (error) {
    list.textContent = "Could not load the data";
  }
}
